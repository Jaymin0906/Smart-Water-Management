Prediction Logic & Mathematical Model

Deterministic Rate Model

AquaPulse calculates tank-empty estimates using historical telemetry pairs. The engine analyzes valid consecutive readings separated by a minimum threshold of time:

Consumption Rate (R) = Δ Level / Δ Time (hours)
Time to Empty (T) = Current Level / R
Projected Empty Timestamp = Now + T

Note: If the pump is actively refilling the tank or water is static, the system safely suppresses depletion alerts to prevent erroneous negative values or division by zero.
